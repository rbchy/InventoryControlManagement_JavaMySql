३. মাসিক খরচ বিশ্লেষণ (SQL Query):

  MySQL Query:
  ──────────────────────────────────────────
  SELECT 
    m.material_name,
    SUM(st.quantity) as total_moved,
    SUM(st.quantity * m.current_price) as value
  FROM stock_transactions st
  JOIN materials m ON st.material_id = m.material_id
  WHERE MONTH(st.transaction_date) = MONTH(NOW())
  GROUP BY m.material_id;
