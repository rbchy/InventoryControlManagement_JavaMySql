🚀 দ্রুত শুরু করুন (Quick Start - ५ মিনিটে)
════════════════════════════════════════════════════════════════════════════════

Step 1: প্রয়োজনীয় সফটওয়্যার ইনস্টল করুন
  ├─ Java JDK 11+ (oracle.com/java)
  ├─ MySQL 8.0 (dev.mysql.com)
  ├─ IDE (Eclipse/IntelliJ)
  └─ MySQL Connector JAR (mysql-connector-java-8.0.33.jar)

Step 2: ডাটাবেস সেটআপ করুন
  ├─ MySQL Command Line খুলুন
  ├─ 01_database_schema.sql চালান
  └─ SHOW TABLES; দিয়ে যাচাই করুন

Step 3: Java প্রজেক্ট তৈরি করুন
  ├─ নতুন Java প্রজেক্ট খুলুন
  ├─ MySQL Connector JAR যোগ করুন
  └─ সকল .java ফাইল কপি করুন

Step 4: প্রোগ্রাম চালান
  └─ InventoryManagementApp.java চালান

Step 5: পরীক্ষা করুন
  └─ মেনু থেকে বিভিন্ন অপশন ট্রাই করুন

  ⚠️  প্রথমে DatabaseConfig.java তে main() চালান

🔧 ট্রাবলশুটিং টিপস (Troubleshooting Tips)
════════════════════════════════════════════════════════════════════════════════

সমস্যা: "Database connection failed"
  সমাধান: 
  ├─ MySQL চালু আছে কি যাচাই করুন
  ├─ localhost এবং port 3306 ঠিক কি যাচাই করুন
  └─ Username এবং password সঠিক কি যাচাই করুন

সমস্যা: "ClassNotFoundException: com.mysql.cj.jdbc.Driver"
  সমাধান:
  ├─ MySQL Connector JAR ডাউনলোড করুন
  ├─ প্রজেক্টে যোগ করুন
  └─ IDE রিস্টার্ট করুন

সমস্যা: "Table doesn't exist"
  সমাধান:
  ├─ 01_database_schema.sql সম্পূর্ণভাবে চালান
  ├─ "SHOW TABLES;" দিয়ে যাচাই করুন
  └─ সব টেবিল থাকা উচিত

সমস্যা: "No rows in result set"
  সমাধান:
  ├─ প্রথমে নমুনা ডেটা যাচাই করুন
  ├─ SELECT * FROM suppliers; চালান
  └─ ডেটা নেই হলে নমুনা ডেটা ইনসার্ট করুন
