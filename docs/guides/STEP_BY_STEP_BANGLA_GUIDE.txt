প্রথম অংশ: পরিবেশ স্থাপন (Environment Setup)
============================================================================

📌 ধাপ ১: প্রয়োজনীয় সফটওয়্যার ইনস্টল করুন
────────────────────────────────────────────────────────

১.১) Java Development Kit (JDK) ইনস্টল করুন:
   • JDK 11 বা তার উপরের সংস্করণ ডাউনলোড করুন
   • https://www.oracle.com/java/technologies/downloads/
   • ইনস্টলেশনের পরে যাচাই করুন:
     $ java -version
     $ javac -version

১.२) MySQL সার্ভার ইনস্টল করুন:
   • MySQL সংস্করণ 8.0 ডাউনলোড করুন
   • https://dev.mysql.com/downloads/mysql/
   • ইনস্টলেশনের সময়:
     * Root পাসওয়ার্ড নির্ধারণ করুন (যেমন: root123)
     * Port: 3306 (ডিফল্ট)
   • MySQL চালু করুন:
     Windows: net start MySQL80
     Linux/Mac: brew services start mysql

१.३) IDE (সম্পাদনা সফটওয়্যার) ইনস্টল করুন:
   নীচের যেকোনো একটি ব্যবহার করুন:
   • IntelliJ IDEA
   • Eclipse
   • NetBeans
   • VS Code + Extension

१.४) MySQL Connector জার ফাইল ডাউনলোড করুন:
   • mysql-connector-java-8.0.33.jar ডাউনলোড করুন
   • https://dev.mysql.com/downloads/connector/j/
   • এটি আপনার প্রজেক্টের lib ফোল্ডারে রাখুন

📌 ধাপ २: MySQL ডাটাবেস তৈরি করুন
────────────────────────────────────────

२.१) MySQL Command Line খুলুন:
   $ mysql -u root -p
   (আপনার পাসওয়ার্ড দিন)

२.२) SQL স্কিমা চালান:
   নীচের কমান্ড চালান:

   mysql> CREATE DATABASE pharma_inventory;
   mysql> USE pharma_inventory;
   mysql> source path/to/01_database_schema.sql;

   যাচাই করুন:
   mysql> SHOW TABLES;
   (১৭টি টেবিল দেখা যাবে)

२.३) সাপ্লায়ার যোগ করুন (Verify Data):
   mysql> SELECT * FROM suppliers;
   (তিনটি সাপ্লায়ার দেখা যাবে)

२.४) ম্যাটেরিয়াল দেখুন:
   mysql> SELECT * FROM materials;
   (৫টি ম্যাটেরিয়াল দেখা যাবে)

२.५) ইনভেন্টরি দেখুন:
   mysql> SELECT * FROM inventory;
   (ইনভেন্টরি রেকর্ড দেখা যাবে)

সপ্তম অংশ: ডাটাবেস কোয়েরি এবং রিপোর্ট (Queries & Reports)
============================================================================

📌 ধাপ ७: উপকারী SQL কোয়েরি
─────────────────────────────

७.१) ইনভেন্টরি সারসংক্ষেপ (Inventory Summary):
   ──────────────────────────────────────────

   mysql> SELECT 
   - material_code
   - material_name
   - current_quantity
   - available_quantity
   - stock_value
   - stock_status
   FROM inventory_summary;

७.२) কম স্টক আইটেম (Low Stock Items):
   ──────────────────────────────────

   mysql> SELECT * FROM low_stock_items;

७.३) সাম্প্রতিক লেনদেন (Recent Transactions):
   ────────────────────────────────────────

   mysql> SELECT * FROM recent_transactions LIMIT 10;

७.४) মোট ইনভেন্টরি মূল্য (Total Inventory Value):
   ───────────────────────────────────────────

   mysql> SELECT 
   SUM(current_quantity * current_price) as total_value
   FROM inventory i
   JOIN materials m ON i.material_id = m.material_id;

७.५) সাপ্লায়ার অনুযায়ী ক্রয় (Purchases by Supplier):
   ──────────────────────────────────────────────

   mysql> SELECT 
   s.supplier_name,
   COUNT(*) as po_count,
   SUM(po.total_amount) as total_spent
   FROM purchase_orders po
   JOIN suppliers s ON po.supplier_id = s.supplier_id
   GROUP BY s.supplier_id, s.supplier_name;

অষ্টম অংশ: সাধারণ সমস্যা এবং সমাধান (Troubleshooting)
============================================================================

❌ সমস্যা १: "SQLException: Communications link failure"
────────────────────────────────────────────────────

কারণ: MySQL চালু নেই বা সংযোগ তথ্য ভুল

সমাধান:
१) MySQL চালু আছে কি না যাচাই করুন:
   Windows: Services.msc খুলুন → MySQL80 খুঁজুন
   Linux/Mac: sudo brew services list

२) DatabaseConfig.java তে সংযোগ তথ্য যাচাই করুন:
   - DB_URL সঠিক কি?
   - DB_USER সঠিক কি?
   - DB_PASSWORD সঠিক কি?

३) MySQL Command Line দিয়ে সংযোগ পরীক্ষা করুন:
   $ mysql -u root -p
   (সফল হলে MySQL ঠিক আছে)

❌ সমস্যা २: "ClassNotFoundException: com.mysql.cj.jdbc.Driver"
─────────────────────────────────────────────────────────

কারণ: MySQL Connector JAR যুক্ত নেই

সমাধান:
१) IDE তে Project Properties খুলুন
२) Libraries/Build Path যান
३) mysql-connector-java-8.0.33.jar যোগ করুন
४) প্রজেক্ট পুনরায় বিল্ড করুন

❌ সমস্যা ३: "Access denied for user 'root'@'localhost'"
─────────────────────────────────────────────────────

কারণ: পাসওয়ার্ড ভুল

সমাধান:
१) MySQL Command Line খুলুন:
   $ mysql -u root -p
२) সঠিক পাসওয়ার্ড দিন
३) DatabaseConfig.java তে একই পাসওয়ার্ড ব্যবহার করুন

❌ সমস্যা ४: "Database 'pharma_inventory' doesn't exist"
─────────────────────────────────────────────────────

কারণ: ডাটাবেস তৈরি হয়নি

সমাধান:
१) MySQL Command Line খুলুন
२) নীচের কমান্ড চালান:
   mysql> CREATE DATABASE pharma_inventory;
   mysql> USE pharma_inventory;
   mysql> source path/to/01_database_schema.sql;

❌ সমস্যা ५: "Insufficient stock quantity"
────────────────────────────────────────

কারণ: ইস্যুর জন্য যথেষ্ট স্টক নেই

সমাধান:
१) পরিমাণ হ্রাস করুন
२) আগে ক্রয় অর্ডার গ্রহণ করুন
३) স্টক অবস্থা দেখুন (মেনু অপশন ১)
